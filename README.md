# โมเดล 3D ย้ายเสาไฟฟ้า ทล.222 กม.6+085

โมเดล 3 มิติ (three.js r128) สะพานคู่ PC Box Beam ตามแบบกรมทางหลวง และแนวเสาไฟฟ้า 115/22 kV เพื่อประสานงาน ไม่ใช่แบบก่อสร้าง ค่าที่ไม่มีในแบบเป็นค่าสมมติ

- `index.html` โมเดลหลัก, `parts.html` ชุดอุปกรณ์หัวเสา
- `assets/*.js` ชิ้นส่วนที่ปั้นใน Blender (GLB base64)

ไฟล์ชุดนี้คัดลอกมาจาก repo งานหลัก (private) ให้แก้ที่ repo หลักแล้วคัดลอกมาที่นี่
